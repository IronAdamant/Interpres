# Caption helper protocol

One UTF-8 line per message. No JSON crates in core.

```
READY
STATUS lc=running|stopped|degraded reason=...
PARTIAL text=...
FINAL text=...
ERROR message=...
LOG level=info|warn|error message=...
SHUTDOWN
```

Spaces in values use percent-encoding (`%20`, `%0A`, `%25`, `%3D`).
